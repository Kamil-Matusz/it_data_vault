# Claude Code — Audyt promptów i instrukcji

## 🎯 Cel

Komenda `/claude-api prompt-audit` analizuje cały folder projektowy i wskazuje, co można poprawić w promptach, instrukcjach oraz konfiguracji projektu, aby **Claude Code pracował skuteczniej i lepiej realizował zadania**.

## 🔍 Jak to działa?

1. **Analiza projektu** — Claude przegląda folder projektowy i ocenia istniejące instrukcje oraz prompty.
2. **Identyfikacja problemów** — wskazuje elementy, które warto poprawić lub zoptymalizować.
3. **Uzasadnienie zmian** — wyjaśnia, dlaczego proponowane poprawki mają sens i jakie mogą przynieść korzyści.
4. **Wdrożenie poprawek** — po przejrzeniu rekomendacji możesz zlecić Claude Code wprowadzenie wybranych zmian.

## 💡 Kiedy warto użyć?

Szczególnie warto uruchomić ten audyt, jeśli:

- pracujesz z **Claude Code** na co dzień;
- przechodzisz na nowszy model, np. **Opus 5.5**;
- korzystasz z rozbudowanych plików instrukcji, promptów i konfiguracji agentów;
- chcesz poprawić jakość odpowiedzi oraz ograniczyć błędy wynikające z nieprecyzyjnych instrukcji.

Nowsze generacje modeli mogą inaczej interpretować instrukcje i lepiej reagować na inne sposoby formułowania promptów. Dlatego warto zweryfikować, czy dotychczasowa konfiguracja nadal jest optymalna.

## ✅ Rekomendacja

Warto zarezerwować około **godziny na przeprowadzenie audytu, przejrzenie rekomendacji i wdrożenie najważniejszych poprawek**.

Nie akceptuj jednak zmian automatycznie — sprawdź, czy rzeczywiście poprawiają konfigurację i nie usuwają istotnych reguł projektowych.

**Cel:** dostosować instrukcje Claude Code do aktualnego modelu i sprawić, żeby narzędzie skuteczniej wykonywało codzienną pracę programistyczną.
