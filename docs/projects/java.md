# Java Projects

## PetroTrend

A fuel price tracking application (ON, PB95, PB98, LPG). The backend is a Spring Boot REST API backed by MongoDB; the frontend is a React + TypeScript UI styled after a roadside station price pylon.

- **Stack:** Spring Boot, MongoDB, React, TypeScript
- **Repo:** [github.com/Kamil-Matusz/PetroTrend](https://github.com/Kamil-Matusz/PetroTrend)

## Design-Patterns

- **Stack:** Java
