# .NET Projects

## CertiBlock

Research system for evaluating the efficiency of blockchain technologies (Ethereum & Polygon) in the registration and verification of digital certificates.

- **Stack:** .NET, Ethereum, Polygon, Solidity
- **Repo:** [github.com/Kamil-Matusz/CertiBlock](https://github.com/Kamil-Matusz/CertiBlock)

## Asklepios

A system supporting and offering support for medical facilities. Technical part of the engineering thesis.

- **Stack:** .NET
- **Repo:** [github.com/Kamil-Matusz/Asklepios](https://github.com/Kamil-Matusz/Asklepios)

## CleanArchitecture

A lightweight, opinionated `dotnet new` project template for ASP.NET Core Web API applications following the principles of Clean Architecture (Onion Architecture).

- **Stack:** ASP.NET Core Web API, `dotnet new` template
- **Repo:** [github.com/Kamil-Matusz/CleanArchitecture](https://github.com/Kamil-Matusz/CleanArchitecture)

## BlacklistPoker

A private record book of people who wronged you, drawn as a deck of playing cards. Each entry collects violations worth 1-100 points; the total drives the card's suit (♣ → ♦ → ♥ → ♠) and its place in your standings. Polish UI.

- **Stack:** ASP.NET Core 10, Cosmos DB, React 19, JWT
- **Repo:** [dev.azure.com/Awahir/BlacklistPoker](https://dev.azure.com/Awahir/BlacklistPoker)
